# Guru Chlorine App

Unified repository containing the mobile applications, web dashboard, and AI services for water quality testing, chlorine monitoring, and disease prevention.

## Project Structure

- **`dph_mob_app_mosqito/`**: React Native mobile application for mosquito monitoring, inspection, and water testing workflows.
- **`dph_mos_water_app_dash/`**: Web application dashboard, Express.js backend API, and AI analysis backend (`guru_backend_ai`).
- **`dph_ts_app_cd/`**: TypeScript Expo mobile application for water quality and larva monitoring.
